# Third-party assets

## `sphinx_warehouse.glb`

- **Title:** Great Sphinx of Giza
- **Author:** 3dHH (M. Manhart, www.3dHH.de)
- **Source:** SketchUp 3D Warehouse, model ID `7ee790a94d0c7d57ae504fdbdb5a7e96`, published 2009
- **Derivation:** Based on the original Giza pyramids and Sphinx model by the Egyptian Tourist Authority, divided and adapted for Google Earth by 3dHH
- **Original page:** https://3dwarehouse.sketchup.com/model/7ee790a94d0c7d57ae504fdbdb5a7e96
- **Use here:** The mesh is imported into the Giza scene, scaled to 73 m length, re-UV'd and re-textured with the project's procedural limestone. It is intended for this local educational visualization. Check the current 3D Warehouse terms before redistributing the model or using it commercially.
- **Geometry:** approximately 2,100 polygons, 2,497 vertices after import; low-poly by design, not a photogrammetric high-resolution scan.

The pyramids, terrain, mastabas, temples, enclosure and all other geometry in this project are original procedural work.
