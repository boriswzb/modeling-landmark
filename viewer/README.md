# 吉萨金字塔群 · 在线 3D 查看器

浏览器中的实时三维场景，支持自由旋转、缩放、平移、模型分解、标签聚焦、日间/黄昏光照和线框模式。

## 打开

在本机运行：

```powershell
cd D:\建模
python -m http.server 8765 --bind 127.0.0.1
```

然后打开：

**http://127.0.0.1:8765/viewer/**

也可以双击根目录的 `start_viewer.bat`，它会启动服务并打开浏览器。

> 不能直接双击 `viewer/index.html`。浏览器会因 `file://` 的同源策略拒绝加载 ES Module 和 GLB，必须通过本地 HTTP 服务访问。

## 操作

| 操作 | 方式 |
|---|---|
| 旋转 | 鼠标左键拖拽 / 单指拖拽 |
| 缩放 | 滚轮 / 双指捏合 |
| 平移 | 鼠标右键拖拽 / 双指拖动 |
| 聚焦建筑 | 点击金字塔上方标签或左侧信息卡“聚焦此建筑” |
| 模型分解 | 拖动“模型分解”滑块，或按 `E` |
| 自动旋转 | 点击“自动旋转”，或按 `Space` |
| 标签开关 | 点击“标签”，或按 `L` |
| 线框模式 | 点击“线框”，或按 `W` |
| 回到主视 | 点击“主视”，或按 `R` |
| 光照切换 | 点击“日间/黄昏”按钮 |

移动端默认收起控制面板，点击底部“点击 − 展开控制面板”即可展开；场景中的金色圆点可点击。

## 功能

- **实时 3D**：Three.js WebGL，本地渲染，无视频流。
- **模型分解**：三大金字塔、王后金字塔、狮身人面像、神庙、马斯塔巴与地形沿垂直轴分层抬升，并显示原始基座轮廓。
- **相机预设**：主视 / 鸟瞰 / 狮身 / 平面。
- **地标标签**：胡夫、哈夫拉、门卡乌拉、狮身人面像，点击飞行聚焦并显示尺寸信息。
- **光照**：黄昏与日间两套天空、太阳和雾参数。
- **线框**：查看金字塔内部石砌层与地形网格。
- **移动端适配**：自动切换相机视野，触摸操作，控制面板可收起。

## 部署到静态网站

把 `viewer/` 文件夹和 `Giza_Pyramids.glb` 按上面的相对位置一起上传到任意静态托管（Nginx、GitHub Pages、Cloudflare Pages、对象存储等），无需构建步骤。模型路径为 `../Giza_Pyramids.glb`，所以请保持 `viewer/` 与 GLB 同级。

## 说明

- 模型是**现存遗迹状态**的风格化复原；狮身人面像采用低多边形扫描体块（3D Warehouse / 3dHH），适合中远距离观看，面部细节有限。马斯塔巴布局和地形细节亦为示意级。

## Sphinx 模型来源

`assets/sphinx_warehouse.glb`：

- 3D Warehouse “Great Sphinx of Giza”，作者 3dHH，2009
- 基于 Egyptian Tourist Authority 的原始 Giza 模型改编
- 本项目中缩放至 73 m 长、重新 UV 并贴图；仅用于本地教育展示
- 对外再分发或商用前请核对 3D Warehouse 当前条款，详见 `assets/README.md`
- 首次加载需下载 27 MB 的 GLB；本地访问通常 1–3 秒，之后由浏览器缓存。
- 桌面端集显下建议使用 1600×900 或更低窗口；移动端会自动降低像素比。
